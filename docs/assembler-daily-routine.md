# Рабочий день сборщика

Инструкция для сборщика склада: полный цикл дня — от утреннего сбора заказов на Ozon до вечерней
отгрузки в ВМС. Написана для новых сотрудников, порядок шагов важен.

## Что нужно для работы

- Доступы в кабинеты Ozon Seller всех трёх магазинов: **МК**, **ПА**, **ФМ**
- Доступ в ВМС с правом синхронизации интеграций (без него кнопки «Синхронизировать заказы» не видно)
- Принтер этикеток
- Листик и ручка — записи ведутся весь день, см. [Листик](#листик-весь-день)

## Времена отсечки

| Магазин | Отсечка |
| ------- | ------- |
| МК      | 11:30   |
| ПА      | 12:30   |
| ФМ      | 13:30   |

После своей отсечки магазин в этот день больше не досбирается: в 12:30 работаем с ПА и ФМ,
в 13:30 — только с ФМ.

## Начало дня

### Ozon — собрать заказы во всех магазинах

По очереди зайти в кабинет каждого магазина (МК, ПА, ФМ) и нажать **«Собрать все»**. Магазины
переключаются вручную, ни один не пропускать.

### ВМС — синхронизация

1. Открыть **Операции → Заказы → FBS**.
2. Нажать **«Синхронизировать заказы»** в шапке страницы.
3. В окне синхронизации нажать кнопку-ярлык **«Все Ozon»** — она отметит все озоновские магазины разом.
4. Нажать **«Синхронизировать»**.
5. Дождаться окончания и развернуть аккордеон каждого магазина — там результат прогона.
   Убедиться, что пропусков не было.

> **Пропуски.** Если в результатах есть пропуски («карточек без привязки», «склад не привязан»,
> «ключ не читается») — самому не чинить, позвать старшего. Сборку не начинать, пока не разберутся.

### Этикетки и «Взять на себя»

1. На странице «Заказы FBS» поставить фильтр статуса → **«Подтверждён»**. Это внутренний статус ВМС
   (селект «Все статусы»), не статус на площадке.
2. Увеличить размер страницы до **200**, чтобы все заказы поместились на одну страницу.
3. Отметить галочку **«выбрать все»** в шапке таблицы.
4. В нижней плашке нажать **«Скачать этикетки»** и сразу распечатать на этикеточном принтере.
5. Там же нажать **«Взять на себя (N)»** — заказы уйдут в раздел «Сборка».

### Физическая сборка

Собрать заказы по распечатанным этикеткам, этикетки наклеить на упаковку.

## Волны отсечек (11:30 / 12:30 / 13:30)

В каждой временной точке алгоритм одинаковый, меняется только магазин, у которого сейчас отсечка.

### Ozon — досбор

В кабинете магазина с текущей отсечкой нажать **«Собрать все»** — подберутся заказы, накопившиеся
с прошлого прохода.

### ВМС — синхронизация и этикетки

1. **Операции → Заказы → FBS** → **«Синхронизировать заказы»** → **«Все Ozon»** → запустить.
2. Проверить аккордеоны на пропуски.
3. Фильтр статуса → **«Подтверждён»**, по всем магазинам сразу — по конкретному магазину не фильтруем.
4. Выбрать все → **«Скачать этикетки»** → распечатать.
5. **«Взять на себя»**.
6. Собрать новые заказы, наклеить этикетки.

### Ozon — этикетки в групповой чат

1. Вернуться в кабинет магазина, у которого прошла отсечка.
2. Вкладка **«Ожидает отгрузки»**.
3. Выделить все заказы, скачать этикетки (PDF).
4. Отправить PDF в групповой чат — по нему на ПВЗ отпикают отправления.

> На этом шаге в Ozon **только скачиваются этикетки**. Отгрузка не нажимается, акт не формируется.

## Листик (весь день)

Форма свободная, но записывать нужно всё и сразу, не по памяти:

- **Возвраты** — что и сколько взято из возвратов
- **Брак** — какой брак и сколько обнаружено
- **Расхождения** — где фактическое количество на полке не совпало с ВМС
- **Wildberries** — состав отгрузок за день
- **Прочее** — Авито и остальные площадки

По ВБ и прочим площадкам товар собирается физически по ходу дня, а в ВМС проводится вечером
прямыми заказами — состав берётся с листика.

## Конец дня

Порядок строгий.

### 1. Внести данные с листика в ВМС

1. **Операции → Приемки** — одна приёмка на все возвраты за день.
2. **Операции → Списания** — одно списание на весь брак за день.
3. **Операции → Инвентаризации** — одна инвентаризация на все расхождения за день.

> Расхождения обязательно проводятся **до** финальной сборки, иначе в сборке не сойдутся остатки.

### 2. Создать два прямых заказа

**Операции → Заказы → Прямые → создать.** Нужно два заказа:

1. **Wildberries** — сводный за день, состав с листика.
2. **Прочее** — Авито и остальные площадки, всё в один заказ; источники внутри не помечаются.

Особых требований к оформлению нет. Оба заказа сразу **взять на себя**, чтобы они попали в «Сборку».

### 3. Финальная сборка в ВМС

1. Открыть **Операции → Заказы → Сборка** — там все заказы, взятые на себя за день.
2. **«Выбрать все»** → **«Собрать выбранные (N)»**.
3. Откроется окно **«Массовая сборка»**. Одинаковые товары из разных заданий сведены в одну строку,
   колонки: **Позиция / Итого / Источник / Статус**.

Статус строки:

| Чип                     | Что значит                             | Что делать                            |
| ----------------------- | -------------------------------------- | ------------------------------------- |
| зелёный **«готово»**    | строка заполнена                       | ничего                                |
| **«нужна ячейка»**      | не выбрано, откуда брать               | выбрать ячейку в колонке «Источник»   |
| **«нужен вариант»**     | товар с вариациями, вариант не выбран  | раскрыть строку и выбрать вариант     |
| **«задать состав»**     | комплект, состав не собран             | раскрыть строку и заполнить состав    |

По типам позиций:

- **Простой товар** — ячейка подставляется автоматически (склад по умолчанию) прямо в колонке
  «Источник», рядом видно доступный остаток. Проверить и при необходимости сменить; строку
  раскрывать не нужно.
- **Товар с вариациями** — кликнуть по строке, она раскроется. Внутри выбрать **Вариант**.
  Если выбранный вариант сам оказался вариацией, ниже появится ещё один список — выбирать до конца
  цепочки. После выбора появится либо выбор ячейки, либо состав; заполнить и его. Смена варианта
  сбрасывает всё, что заполнено ниже.
- **Комплект** — раскрыть строку и заполнить состав: дерево компонентов, у каждого своя ячейка.
  Счётчик «X из Y» показывает, сколько слотов не заполнено, рядом кнопка перехода к первому пустому.

> **«Состав ×1».** Состав и вариант задаются один раз на всю группу и применяются ко всем её
> заданиям. В плашке написано, к скольким заданиям применится и сколько спишется. Раскрыв строку,
> над составом видно список заказов, в которые уйдёт позиция.

4. Когда все строки зелёные — нажать **«Собрать N заданий»**. Пока внизу горит красное
   «Не готово: N групп», кнопка неактивна: искать строки без зелёного чипа.
5. Ошибка **«Не хватило остатков»** означает, что расхождение не проведено инвентаризацией.
   Галка «Сохранять успешные позиции при ошибках» по умолчанию выключена, поэтому вся партия
   откатывается целиком и ничего не собирается. Позвать старшего; галку самому не включать.

### 4. Отгрузка

Сразу после сборки нажать **«Отгрузить»** по собранным заказам. День закрыт.

## Короткая памятка

```
Утро:       Ozon «Собрать все» ×3 → ВМС синх → проверить пропуски → этикетки → взять на себя → собрать
11:30 МК ─┐
12:30 ПА  ├─ Ozon «Собрать все» → ВМС синх → этикетки → взять на себя → собрать
13:30 ФМ ─┘   → Ozon «Ожидает отгрузки» → этикетки PDF → в групповой чат
Весь день:  листик — возвраты / брак / расхождения / ВБ / прочее
Вечер:      приёмка → списание → инвентаризация → 2 прямых заказа → Сборка → Отгрузить
```
